 # Demo Video Script (~90 seconds)

## Setup Before Recording
- Open QuickTime Player → File → New Screen Recording
- Have the app closed, ready to double-click
- Make the window about 80% of screen width so text is readable

---

## Script

### 1. Open the App (5s)
**[Double-click "Quran Recitation Translator.app"]**

> "This is the Quran Recitation Translator — it listens to Quran recitation in real time and shows the Arabic verse with its English translation."

---

### 2. Login with Quran.Foundation (15s)
**[Click "Login" button]**

> "The app integrates with Quran.Foundation's OAuth2 API. I'll sign in now."

**[Browser opens → sign in → redirect back]**

> "Logged in. The app now syncs bookmarks and reading history to the cloud."

---

### 3. Test Verse Recognition (15s)
**[Click "Test Recognition"]**

> "Let me demonstrate the verse matching. The app recognizes Arabic text, matches it against the full Quran — all 114 surahs — and displays the English translation instantly."

**[Point out: Arabic text right-aligned, English below, status showing match confidence]**

---

### 4. Live Recitation (20s)
**[Click "Start Listening" → Recite Surah Al-Fatihah or any short verse]**

> "Now I'll recite live. The app captures audio, sends it to speech recognition, then matches the verse locally — no API call needed per verse, so it works at recitation speed."

**[Click "Stop Listening" after a verse or two]**

---

### 5. Bookmark a Verse (10s)
**[Click "Bookmark Verse"]**

> "I can bookmark any verse for later."

**[Click "Bookmarks" tab]**

> "And here are my saved bookmarks with the Arabic and translation."

---

### 6. History (5s)
**[Click "History" tab]**

> "The app also automatically tracks my reading history as I recite."

---

### 7. Collections (5s)
**[Click "Collections" tab → Click "New Collection" → type "Daily Adhkar"]**

> "I can organize verses into collections."

---

### 8. Wrap Up (10s)
**[Switch back to Translator tab]**

> "The app uses three Quran.Foundation APIs: the Content API for Quran data, OAuth for authentication, and the User API for bookmarks and history. All verse matching happens offline for speed. Thank you."

---

## Key Points to Hit
- Content API ✓ (verse data)
- User API ✓ (bookmarks, history, collections)
- OAuth ✓ (login flow)
- Real-time speech recognition
- Offline verse matching (fast)
- 114 surahs, full translations
